# 逆向流程依赖图与待确认问题

> 本文记录当前平台已经落地的“纠错型逆向”能力,以及后续正式退货/退款/库存账本需要确认的问题。  
> 这里的逆向不是自动级联,而是由操作者按“先撤下游,再撤上游”的顺序逐步处理。

## 一、已经做了的

### 1. 销售单取消

- 已确认销售单可以取消。
- 如果存在活动采购单或活动出库单,取消销售单会被拒绝。
- 取消后销售单进入已取消,来源报价回到锁档,可修改后重新转销售。

### 2. 采购单取消

- 草稿/已确认采购单可以取消。
- 取消后释放销售单行的采购覆盖量。
- 如果采购单下存在活动入库单,取消采购单会被拒绝。

### 3. 入库单作废与撤销入库

- 在途入库单可以作废。
- 已入库入库单可以撤销入库,状态回到在途。
- 撤销入库会让对应应付款作废留痕,库存派生数量回落。
- 如果应付款已核销,必须先反核销付款。
- 如果货已被出库消费,必须先撤销出库。

### 4. 出库单取消与撤销出库

- 草稿出库单可以取消。
- 已出库出库单可以撤销出库,状态回到草稿。
- 撤销出库会让对应应收款作废留痕,库存可发数量按单据状态自然恢复。
- 如果应收已核销,必须先反核销收款。
- 如果所在柜已封柜或已离港,必须先把柜退回 OPEN。

### 5. 发运柜纠错

- OPEN 柜可以取消,但柜下不能有活动出库单。
- 已封柜可以撤封柜回 OPEN;如果有活动报关记录,必须先作废报关记录。
- 已离港可以撤离港回已封柜;如果有活动物流节点,必须先作废物流节点。
- 报关记录和物流节点当前是底层软删留痕,退出当前有效视图。

### 6. 财务反核销与作废

- 收款单/付款单支持反核销。
- 反核销只针对指定核销记录,恢复收/付款单未分配余额和应收/应付余额。
- 收款单/付款单可以作废,但存在活动核销记录时必须先逐条反核销。

## 二、当下可以直接做的

这些事项不改变业务结果,只增强可理解性、命名准确性和测试保护。

- 平台导览 `/guide` 新增“逆向/纠错”页,以阻断树说明当前规则。
- 报关和物流前端业务文案从“删除”改为“作废/撤销”,底层仍使用软删机制。
- 补后端 API 集成测试,覆盖“有下游则拦、先处理下游后放行”的关键路径。
- 文档化库存边界:当前库存是按销售单履约库存,不是仓库自由库存账。

## 三、逆向依赖图

```text
取消销售单
  先取消采购单
    先处理入库单
      在途入库单:作废
      已入库入库单:撤销入库
        若应付款已核销:先反核销付款
        若货已被出库消费:先撤销出库
  先处理出库单
    草稿出库单:取消
    已出库出库单:撤销出库后取消
      若应收已核销:先反核销收款
      若柜已封/已离港:先把柜退回 OPEN
        若有物流节点:先作废物流节点,再撤离港
        若有报关记录:先作废报关记录,再撤封柜

作废收款单/付款单
  若存在活动核销记录:先逐条反核销
```

## 四、库存边界

当前库存方案是“按销售单履约库存”的正式设计,不是临时过渡。

成立前提:

- 货从采购起唯一归属某一张销售单。
- 系统没有自由库存。
- 库存页回答的是某销售单某 SKU 到了多少、发了多少、还能发多少。

在这个前提下,库存由单据链实时派生更稳,因为不会出现库存表和业务单据不一致。

触发库存模型升级的信号:

- 退货可以重新可售,并且不再绑定原销售单。
- 允许把某销售单库存转配给另一张销售单。
- 需要盘点、报损、调拨、仓库/库位。
- 需要批次、箱号、扫码追溯。
- 履约后台要承担坦桑仓或门店 POS 的真实库存。

一旦出现这些信号,库存模型应升级为仓库维度真实库存账本;这不是当前逆向纠错的局部改动。

## 五、需要确认后才能开发的

### 1. 客户退货

- 是否允许退货?
- 是否允许部分退货?
- 退回后是否回可售库存?
- 是否需要质检、残次品区、附件和审批?

### 2. 供应商退货

- 已入库后发现问题,是退供应商、换货、补货,还是冲减应付?
- 库存如何扣减?
- 应付款、已付款如何处理?

### 3. 退款、贷项与冲销

- 客户已付款后退款,是原路退、挂预收、冲未来订单,还是生成贷项?
- 供应商已付款后退货,是供应商退款、挂预付、还是冲未来应付?
- 是否存在红字单、冲销单、调整单?

### 4. 报关与物流正式限制

- 已申报、已放行、已离港、已到港之后,哪些动作业务上允许撤销?
- 哪些动作需要审批?
- 是否要求原因、附件、审批人必填?

### 5. 财务期间和审计

- 已结账或跨期后是否还允许撤销原单?
- 是否必须走调整单或冲销单?
- 核销历史是否需要独立业务页面展示,而不是只查审计日志?

### 6. 权限和审批

- 谁能撤销出库、撤销入库、反核销、作废报关、撤离港?
- 哪些动作需要双人复核?
- 哪些动作必须记录原因?
